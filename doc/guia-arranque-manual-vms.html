Guia manual de arranque de VMs (sin scripts)

Secuencia manual con comandos directos. Copia y ejecuta uno por uno.

No usa funciones, for, if, while ni sleep.

0) Verificacion rapida

  1. Comprueba que libvirt responde. virsh list --all
  2. Lista nombres de VMs disponibles. virsh list --all --name

1) DNS

  1. Arranca DNS principal. virsh start dns-principal
  2. Confirma estado de DNS principal. virsh domstate dns-principal
  3. Arranca DNS delegado. virsh start dns-delegado
  4. Confirma estado de DNS delegado. virsh domstate dns-delegado

2) Datos (MariaDB / MaxScale)

  1. Arranca nodo MariaDB 1. virsh start mariadb-1
  2. Confirma estado MariaDB 1. virsh domstate mariadb-1
  3. Arranca nodo MariaDB 2. virsh start mariadb-2
  4. Confirma estado MariaDB 2. virsh domstate mariadb-2
  5. Arranca nodo MariaDB 3. virsh start mariadb-3
  6. Confirma estado MariaDB 3. virsh domstate mariadb-3
  7. Arranca MaxScale. virsh start maxscale-1
  8. Confirma estado de MaxScale. virsh domstate maxscale-1

3) Redis Cluster (7 nodos)

  1. Arranca Redis 1. virsh start redis-1
  2. Arranca Redis 2. virsh start redis-2
  3. Arranca Redis 3. virsh start redis-3
  4. Arranca Redis 4. virsh start redis-4
  5. Arranca Redis 5. virsh start redis-5
  6. Arranca Redis 6. virsh start redis-6
  7. Arranca Redis 7. virsh start redis-7
  8. Valida el estado de todos los nodos Redis. virsh domstate redis-1 && virsh domstate redis-2 && virsh domstate redis-3 && virsh domstate redis-4 && virsh domstate redis-5 && virsh domstate redis-6 && virsh domstate redis-7

4) Aplicacion backend (Winter actual)

  1. Arranca app Winter 1. virsh start appWinter1
  2. Confirma estado app Winter 1. virsh domstate appWinter1
  3. Arranca app Winter 2. virsh start appWinter2
  4. Confirma estado app Winter 2. virsh domstate appWinter2
  5. Arranca app Winter 3. virsh start appWinter3
  6. Confirma estado app Winter 3. virsh domstate appWinter3

Nota de stack

  1. Arranque automatico por stack (recomendado). bash configuraciones-run.sh
  2. Forzar backend WinterCMS. APP_STACK=winter bash configuraciones-run.sh

5) Balanceadores

  1. Arranca balanceador 1. virsh start lb1
  2. Confirma estado de lb1. virsh domstate lb1
  3. Arranca balanceador 2. virsh start lb2
  4. Confirma estado de lb2. virsh domstate lb2

6) Verificacion final

  1. Revisa estado global de todas las VMs. virsh list --all
  2. Valida estado del cluster Redis desde redis-1. ssh -i ssh-keys/id_rsa -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null userinfrakv@192.168.30.10 "redis-cli -h 127.0.0.1 cluster info | egrep 'cluster_state|cluster_known_nodes'"

Chequeo SSH opcional (manual, sin bucles)

  1. DNS principal. ssh -i ssh-keys/id_rsa -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null userinfrakv@192.168.10.10 "echo ok"
  2. DNS delegado. ssh -i ssh-keys/id_rsa -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null userinfrakv@192.168.10.11 "echo ok"
  3. MaxScale. ssh -i ssh-keys/id_rsa -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null userinfrakv@192.168.30.20 "echo ok"
